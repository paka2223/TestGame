# 서울: 마지막 생존자

서울역과 남산타워를 중심으로 폐허가 된 도시를 탐험하는 2.5D 쿼터뷰 생존 RPG 프로토타입입니다. 구역 가장자리에서 인접한 절차 생성 지역으로 이동할 수 있고, 떠났던 지역의 좀비와 지형 상태는 다시 돌아오면 이어집니다. 바깥은 어둡고 손전등 주변의 좀비만 보입니다.

## 실행

Godot 4.3 이상에서 `project.godot`을 열고 실행하세요.

## 조작

- **마우스 오른쪽 클릭**: 클릭한 곳으로 이동
- **마우스 왼쪽 클릭**: 포인터 방향으로 공격. 마우스 좌표는 등각 투영 맵 좌표로 변환됩니다.
- **WASD / 방향키**: 같은 방향을 2초 유지하면 달리기. 달리는 동안 방향을 바꾸거나 키를 잠깐 다시 눌러도 속도를 유지합니다. 잠시 멈추면 걷기로 돌아옵니다.
- **1–5**: 무기 선택 (1–3 근접, 4 권총, 5 활)
- **R**: 총/활 장전. 탄창과 예비 탄약을 사용하며 장전 중에는 발사할 수 없습니다.
- **Tab**: 인벤토리 열기/닫기. 식량, 고철, 탄약, 화살과 탄창 잔량을 보고 무기를 장착할 수 있습니다.
- **Space**: 마우스 방향 공격
- **F**: 파밍. 식량·고철을 얻고 확률로 탄약 또는 화살을 찾습니다.
- **B**: 고철 3개로 바리케이드 건설 및 체력 회복
- **E**: 건물 근처에서 용병 고용 또는 치료
- 좌측 패널 **접기/펼치기**: 설명과 능력 패널을 숨기거나 표시

## 무기

| 무기 | 피해 | 사거리 | 특징 |
| --- | ---: | ---: | --- |
| 부엌칼 | 7–13 | 1.35 | 빠른 근접 공격 |
| 쇠파이프 | 12–21 | 1.90 | 균형 잡힌 근접 공격 |
| 각목 | 9–17 | 2.25 | 사거리가 긴 근접 공격 |
| 권총 | 18–31 | 9.0 | 탄약 8발, 예비 탄약과 재장전 필요 |
| 활 | 12–23 | 7.0 | 화살 1발씩 장전, 높은 치명타 확률 |

공격 피해는 무기별 범위에서 매번 무작위로 정해집니다. 조준 방향과 사거리를 확인할 수 있고, 명중 시 타격 위치와 피해량, 좀비의 남은 체력이 표시됩니다.

## 지역과 성장

맵 가장자리로 걸어가면 북·남·동·서 방향의 새 폐허 구역으로 이어집니다. 새 지역에는 건물, 소품과 좀비가 생성되고 이미 방문한 지역은 상태를 보존합니다. 미니맵은 현재 구역과 시야 내 좀비를 보여줍니다.

힘은 근접 피해와 생존에, 민첩은 이동과 기력에, 지능은 건설과 치료 역할에 도움을 줍니다. 파티 동료는 선택 사항이며, 건물 근처에서 E를 눌러 용병을 고용할 수 있습니다.
