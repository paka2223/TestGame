# 서울: 마지막 생존자

서울 폐허를 탐험하는 Godot 4.7 쿼터뷰 생존 RPG 프로토타입입니다. 마우스 이동·공격, 능력치 성장, 용병, 인벤토리, 원거리 무기, 시야와 연결된 구역을 포함합니다. 지형은 정적 레이어로 캐시해 카메라가 움직일 때 배경 타일을 매 프레임 다시 그리지 않습니다. 좀비는 사망 시 아이템을 최소 1개 떨어뜨립니다.

## 실행

Godot 4.7 이상에서 `project.godot`을 열고 `Main.tscn`을 실행하세요.

## 조작

- 우클릭 이동, 좌클릭 공격, WASD/방향키 이동
- 같은 방향을 2초 유지하면 달리기. 방향을 바꾸거나 키를 잠시 다시 눌러도 달리기 속도를 유지합니다.
- `1–5` 무기 선택, `R` 장전, `Tab` 인벤토리
- `F` 파밍, `B` 건설, `E` 상호작용, `Space` 공격, `H` 의약품 사용
- 좀비가 떨어뜨린 아이템에 가까이 가면 자동으로 습득합니다.
- 구역 가장자리로 이동하면 새 지역으로 연결됩니다.

## 프로젝트 구조

```text
res://
├── Main.tscn                    # 게임 씬, 컴포넌트 연결
├── scripts/
│   └── game_controller.gd       # 게임 상태와 메인 진행 흐름
├── components/
│   ├── ground_renderer.gd       # 한 번 그린 뒤 재사용하는 정적 지형
│   ├── world_renderer.gd        # 캐릭터, 공격 표시, 아이템 렌더링
│   ├── combat_system.gd         # 공격, 장전, 무기 장착
│   └── game_hud.gd              # 상태 UI, 미니맵, 인벤토리
└── data/
    └── game_config.gd           # 맵 규격, 이동 값, 무기/색상 정의
```

게임 컨트롤러가 공용 게임 상태를 소유하고, 각 컴포넌트는 필요한 작업을 맡습니다. 무기 수치와 공용 상수는 `data/game_config.gd`에서 한곳에 관리합니다. 새 기능은 역할에 맞는 컴포넌트에 추가하고, 서로 다른 컴포넌트 사이 연결은 게임 컨트롤러를 통해 유지하세요.
